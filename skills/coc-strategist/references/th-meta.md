## Scoring Reference

`priority_score = (meta_weight × deficit) + cwl_urgency_bonus + war_frequency_weight`

- **`meta_weight`**: `3.0` for Core Army, Key Equipment, and Key Spells; `2.0` for supporting funnelers/siege/pets; `1.0` for off-meta items.
- **`cwl_urgency_bonus`**: `+2.0` if CWL is within 7 days and the item is currently upgrading.
- **`war_frequency_weight`**: `+1.0` if clan war frequency is `always` and the item impacts war performance.

## TH17

- **Core Army:** 6–7 Root Riders, 3–4 Electro Titans, 4 Healers, funneling Wizards / Baby Dragons.
- **Key Equipment:** BK: Giant Gauntlet + Rage Vial · AQ: Giant Arrow + Healer Puppet · GW: Eternal Tome · RC: Haste Vial + Seeking Shield.
- **Key Spells:** Rage, Heal, Freeze, Overgrowth.
- **Upgrade Priority Notes:** Prioritize Root Rider and Overgrowth Spell in the lab alongside Giant Gauntlet, Eternal Tome, and Spirit Fox before secondary utility troops.
- **CC Request Suggestion:** Root Riders + Valkyries + Freeze (or Poison).

## TH16

- **Core Army:** Root Riders + Throwers or Electro Titans with Healers and funnelers.
- **Key Equipment:** BK: Giant Gauntlet + Rage Vial · AQ: Giant Arrow + Healer Puppet · GW: Eternal Tome · RC: Haste Vial + Seeking Shield (level-adjusted).
- **Key Spells:** Rage, Heal, Freeze, Overgrowth.
- **Upgrade Priority Notes:** Max Root Rider, Thrower, Electro Titan, and Overgrowth Spell first; pair hero upgrades with Spirit Fox and Gauntlet/Tome ore investment.
- **CC Request Suggestion:** Root Riders + Freeze.

## TH15

- **Core Army:** Super Witches + Healers (or LavaLoon with Blizzard/Haze opener).
- **Key Equipment:** GW: Eternal Tome · AQ: Giant Arrow (plus Gauntlet/Vials if unlocked).
- **Key Spells:** Bat, Freeze, Rage, Clone.
- **Upgrade Priority Notes:** Focus lab on Witch/Super Witch, Balloon, Bat Spell, and Clone Spell; keep Grand Warden and Archer Queen prioritized for Eternal Tome and Queen survivability.
- **CC Request Suggestion:** Super Wizard + Balloons + Clone (or Rage + Freeze).

## TH14

- **Core Army:** Electro Dragons + Balloons, or Hog Riders + Miners behind a Queen Charge.
- **Key Equipment:** GW: Eternal Tome (supported by core hero gear).
- **Key Spells:** Rage, Freeze, Lightning.
- **Upgrade Priority Notes:** Max Electro Dragon, Balloon, Hog Rider, Miner, Healer, Rage, and Lightning; Unicorn is the highest-value Pet House unlock for Queen Charge.
- **CC Request Suggestion:** Balloons + Dragon Rider + Rage (or Freeze).

## TH13

- **Core Army:** Yetis + Bowlers smash, or Balloons + Lava Hounds behind a Queen Charge.
- **Key Equipment:** Equipment not yet central in this bracket (prioritize base Hero levels, especially unlocking and leveling Royal Champion).
- **Key Spells:** Rage, Heal, Freeze, Haste.
- **Upgrade Priority Notes:** Upgrade Yeti, Bowler, Balloon, Lava Hound, and Healer early; balance Royal Champion Dark Elixir alongside Queen and Warden.
- **CC Request Suggestion:** Yeti + Valkyrie + Rage (or Freeze).

## TH12

- **Core Army:** Bowlers + Witches (BoWitch) or Electro Dragon + Balloon CC Electrone drop.
- **Key Equipment:** —
- **Key Spells:** Rage, Heal, Freeze, Bat.
- **Upgrade Priority Notes:** Prioritize Bowler, Witch, Balloon, Bat Spell, and Heal/Rage in the lab while pushing Grand Warden to TH12 cap.
- **CC Request Suggestion:** Electro Dragon + Balloon + Clone (or Rage).

## TH11

- **Core Army:** Electro Dragon CC Blimp (Electrone) or Mass Hog Riders + Miners.
- **Key Equipment:** —
- **Key Spells:** Rage, Heal, Freeze.
- **Upgrade Priority Notes:** Unlock and push Grand Warden immediately; max Hog Rider, Miner, Balloon, Heal, and Rage before niche Dark troops.
- **CC Request Suggestion:** Electro Dragon + Balloon + Poison (or Freeze).

## TH10

- **Core Army:** Golems + Hog Riders (GoHo) or Lava Hound + Balloons (LavaLoon).
